# Windows 本地大文件扫描器

一款免安装、完全本地运行的 Windows 大文件扫描与安全清理工具。

## 功能

- 自定义阈值扫描本机固定磁盘，默认 500 MB
- 按体积排序，显示完整路径、修改时间和清理建议
- 标注缓存、安装包、用户文件及系统/程序文件
- 打开所在位置、导出 CSV 清单
- 普通删除前二次确认
- 管理员强制删除，支持被占用文件重启后删除
- 保护 Windows、Program Files、ProgramData、分页/休眠文件及 MuMu 虚拟磁盘
- 完全离线运行，不收集或上传数据

## 下载与使用

下载 `dist/本地大文件扫描器.exe`，双击即可运行，无需安装。需要扫描受保护目录或强制删除时，请右键选择“以管理员身份运行”。

> 删除不会进入回收站，无法撤销，请先核对完整路径。

## 兼容性

推荐 Windows 10 / 11 64 位，依赖系统自带的 .NET Framework 4.x。

## 源码编译

使用 Windows 自带的 .NET Framework C# 编译器即可编译 `src/LargeFileScanner.cs`，并通过 `/win32icon:assets/app.ico` 嵌入图标。
